# 个人贡献与项目介绍

## 个人主页介绍

**皮肤病变分类：传统机器学习分类器设计与性能优化**

基于队友提取的形状、颜色和纹理等多维手工特征，负责传统机器学习分类器设计与性能优化。完成五类基线模型对比，设计“血管性病变识别 → 黑色素瘤与色素痣区分”的两层分类器，结合 mRMR 特征筛选、非对称 PCA、交互特征、XGBoost / SVM 模型选择与二层阈值优化。原课程分组五折评估记录 Macro-F1 为 0.789；原始数据复核过程与结果见仓库报告。

## 面试时可展开的技术点

1. **任务拆分**：两个子任务的有效特征和区分难度可能不同，因此分别选择特征空间与分类器。
2. **非对称特征处理**：L1 尝试通道组内 PCA，L2 保留原始特征，检验不同层是否需要不同降维策略。
3. **分类器优化**：比较 XGBoost 与 RBF-SVM，在训练数据内进行参数选择和二层阈值搜索。
4. **评价指标**：关注 Macro-F1、Balanced Accuracy 与每类召回率，避免只凭总体准确率判断不平衡分类效果。
5. **结果溯源**：区分历史课程结果、原配置复现、最小修改对照和后续简化工程示例，说明每组数字的来源。
